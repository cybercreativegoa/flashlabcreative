Intern testimonial photos (career.html — "What Our Interns Say").

Name each file after the slug used in the card markup, as .jpg:
  rey-dcruz.jpg
  brendan-colaco.jpg
  sample-1.jpg
  sample-2.jpg

Square images, 200x200 or larger. The card shows them at 32x32 cropped
to fill, so anything roughly square works.

If a file is missing the <img> removes itself and the letter avatar shows
instead, so the card never renders broken. Just drop a file in and it
appears — no markup change needed.
